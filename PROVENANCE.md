# Snapshot provenance

This distribution selects scientific artifacts from the fixed prepared-results delivery dated 2026-10-05 and preserves the component models already present in the publication repository. It is a scientific snapshot, not the complete development archive.

Composed model XML files, queries and premise capsules retain their source bytes. Large symbolic XML traces use lossless gzip storage. The decoded trace SHA256 is recorded in the manifest when the stored representation differs.

Public result JSON records select scientifically relevant fields from the archived execution records. They retain findings, formulas, configuration identities, hashes, tool revision, timing, resource measurements and recorded failure status. Local execution paths are normalized in applicable stdout/error text. Result values are not changed to turn failures or inconclusive searches into positive findings.

Proof documents retain their mathematical arguments and limitations; execution-workflow references are replaced by publication paths and the result catalogue. Static certificates are regenerated by the standalone wrappers. These certificates audit premises, and do not represent additional native verifier runs or independent scientific acceptance.

Each manifest entry contains its published SHA256. Where an artifact is copied or derived, the original input SHA256 and storage representation are also supplied. The complete source delivery remains separately retained for audit. No old development Git history is part of this distribution.

The included result records represent the explicitly listed campaigns. They are not an assertion that every historical development experiment has been included. The extended diagnostic campaign was unfinished at the recorded observation time; no later result is inferred.
